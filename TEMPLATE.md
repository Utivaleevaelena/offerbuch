# Шаблон интерактивной оферты — как сделать новую

Приложение — универсальный шаблон: дизайн, конфигуратор, панель «Twoja oferta», форма и отправка писем
работают одинаково для любого клиента. **Всё, что относится к конкретному клиенту, лежит в одном файле:**

```
src/content/proposal.ts        ← тексты, этапы, услуги, цены, письма (польский — основной)
src/content/translations/      ← переводы EN и RU (по желанию)
src/theme.css                  ← цвета (по желанию)
```

Остальной код трогать не нужно.

---

## 1. Создать копию для нового клиента

**Вариант А — GitHub-шаблон (рекомендуется, один раз настроить):**

1. GitHub → репозиторий `offerbuch` → **Settings → General** → поставьте галочку **Template repository**.
2. Для каждого нового клиента: на странице репозитория нажмите **Use this template → Create a new repository**,
   назовите, например, `oferta-studio-nova`.

**Вариант Б — просто попросить Claude:** «Сделай новую оферту для клиента X по шаблону offerbuch,
вот бриф: …» — и приложите текст/транскрипт. Claude заполнит `proposal.ts`.

> Каждый клиент = отдельный репозиторий и отдельный проект в Vercel. Так ссылки, письма
> и выбор клиентов никогда не смешиваются.

## 2. Заполнить `src/content/proposal.ts`

Откройте файл — текущая оферта Gawin & Wojnowska служит полным примером. Меняйте значения, структуру оставляйте.

| Раздел | Что это |
|---|---|
| `id` | короткое имя оферты латиницей, напр. `studio-nova` (ключ для сохранения выбора в браузере) |
| `meta` | заголовок вкладки браузера и описание |
| `client` | логотип текстом (`&` и `×` подсвечиваются), слоган, полное название |
| `agency` | кто готовит оферту (PiXEL EXPERTS TEAM) |
| `hero` | первый экран: заголовок, подзаголовок, кнопки |
| `goal` | секция «Cel projektu» + визуальный процесс |
| `roadmap` | заголовок карты этапов |
| `stages` | **этапы** (порядок в массиве = номера 01, 02, 03…) |
| `services` | **услуги и цены**; поле `category` = `id` этапа |
| `recommended` | блок «Rekomendowany zestaw» (можно удалить целиком) |
| `closing` | финальный призыв отправить оферту |
| `emails` | темы и текст писем администратору и клиенту |

### Правила для услуг

- **Одна услуга в этапе** → большая карточка (как «Strategia», «Sesja»).
- **Несколько услуг в этапе** → карточки-варианты рядом (как «Branding», «Strona», пакеты Outreach).
- Чтобы варианты **взаимоисключали** друг друга, дайте им одинаковый `exclusiveGroup` (например `'web'`).
  Независимые услуги — `exclusiveGroup: null`.
- `billing: 'one_time'` — разовая оплата; `'monthly'` — ежемесячная (считается отдельной суммой, не смешивается с разовыми).
- `id` услуги должен быть уникальным — он приходит в письме.
- Цена — число без пробелов: `priceNet: 3500`.

### Выделение в заголовках

Фрагмент в `*звёздочках*` выделяется курсивом и акцентным цветом:
`title: 'Zbudujmy markę, która przyciąga *właściwych* klientów.'`

### Блоки внутри этапа

В этапе можно добавить готовые блоки (`blocks` — над услугами, `cardBlocks` — внутри большой карточки,
`cardAfter` — в карточке под списком «Co obejmuje?»):

| `type` | Как выглядит | Пример в текущей оферте |
|---|---|---|
| `highlight` | выделенная цитата + текст + мини-процесс | «Kierunek komunikacji» в Strategia |
| `process` | тёмная плашка «шаг → шаг → шаг» | «Jak działa kampania» |
| `chips` | 1–2 карточки со списками-«пилюлями» | критерии фирм / лица принимающие решения |
| `features` | сетка мини-карточек с иконками | «Co obejmuje usługa?» в Outreach |
| `notes` | маленькие пояснения с иконкой | «Gdzie trafiają leady?» |
| `media` | 3 плитки с иконками | «Fotografia / Video / Portrety» |
| `note` | одна серая заметка | «Surowe materiały video…» |
| `compare` | «не говорим / говорим» | «Do czego prowadzimy klienta?» |

Доступные иконки: `check, plus, arrowRight, send, database, sparkle, globe, flame, shield, pen, layers,
rocket, inbox, compass, camera, monitor, mail, palette, info, target, users, document`.

## 3. Языки: польский + английский + русский

Польский (`proposal.ts`) — основная версия: в ней структура, цены и id. Переводы лежат в
`src/content/translations/en.ts` и `ru.ts` и содержат **только тексты**:

- этапы и услуги переводятся по их `id` (`stages: { strategy: {...} }`, `services: { 'website-pro': {...} }`);
- блоки (`blocks`, `cardBlocks`, `cardAfter`) — в том же порядке, что в `proposal.ts`, без `type` и иконок;
- всё, что не переведено, автоматически остаётся на польском — переводить можно постепенно;
- цены в переводы не пишутся: они всегда берутся из `proposal.ts`.

Переключатель PL / EN / RU — в шапке (на телефоне — в меню). Язык запоминается, а ссылку можно
отправить клиенту сразу на нужном языке: `…/?lang=en` или `…/?lang=ru`.

Письмо-подтверждение клиенту приходит на языке, выбранном на сайте. Письмо вам — всегда на польском,
с пометкой «Język strony».

Тексты интерфейса (кнопки, панель «Twoja oferta», форма, ошибки, письма) — в `src/i18n/ui.ts`;
для новой оферты их менять не нужно. Чтобы убрать язык из переключателя, удалите его из
`src/content/translations/index.ts`.

**Удобно:** попросите Claude «переведи proposal.ts на английский и русский» — он заполнит файлы переводов.

## 4. Цвета (по желанию)

В `src/theme.css` поменяйте значения цветов (названия переменных оставьте):
`navy` — основной, `ivory` — фон, `gold` — акцент. Цвета писем — в `server/sendOffer.ts`, константа `C`.

## 5. Проверить локально (по желанию)

```bash
npm install
EMAIL_DRY_RUN=true npm run dev     # письма не отправляются, а печатаются в консоли
npm run build                      # проверка, что всё собирается без ошибок
```

## 6. Опубликовать в Vercel

1. [vercel.com/new](https://vercel.com/new) → выбрать новый репозиторий → **Deploy**.
2. **Settings → Environment Variables** (отметить Production и Preview):

   | Name | Value |
   |---|---|
   | `RESEND_API_KEY` | ключ из Resend (можно один и тот же для всех оферт) |
   | `EMAIL_FROM` | `PiXEL EXPERTS TEAM <oferta@pixelexpertsteam.com>` |
   | `ADMIN_EMAIL` | `elena@pixelexpertsteam.com` |

3. **Deployments → ⋯ → Redeploy** (переменные применяются только к новому деплою).

Домен `pixelexpertsteam.com` в Resend подтверждается **один раз** — для следующих оферт DNS трогать не нужно.

## Чек-лист перед отправкой клиенту

- [ ] Все цены и названия услуг проверены
- [ ] Варианты, которые должны исключать друг друга, имеют одинаковый `exclusiveGroup`
- [ ] Тестовая отправка формы: письмо пришло на `ADMIN_EMAIL`, подтверждение — на адрес из формы
- [ ] Проверено на телефоне (нижняя панель «Twoja oferta»)
- [ ] Переключены EN и RU: нет польских «хвостов» в новых текстах
